# Uso de LLMs no desenvolvimento

## Objetivo

LLMs foram utilizadas como ferramentas de apoio durante o desenvolvimento
deste projeto, principalmente nas etapas de análise, implementação,
debugging, revisão e refinamento da interface.

## Aplicações

- Análise e resolução de problemas de responsividade
- Sugestões de estruturação de componentes
- Revisão de código
- Identificação de possíveis problemas de CSS
- Refinamento da interface
- Apoio na criação e revisão de estilos
- Análise de erros durante o desenvolvimento
- Sugestões de melhorias de acessibilidade

## Processo

As sugestões geradas pelas LLMs foram analisadas, adaptadas,
implementadas e validadas durante o desenvolvimento.

A responsabilidade pelas decisões técnicas e pelo código final
permaneceu com o desenvolvedor.
